# 公众号后台配置指南

只需要做一次，大约 10 分钟。

## 一、注册（如果还没注册）

1. 电脑打开 https://mp.weixin.qq.com ，点右上「立即注册」
2. 账号类型选 **订阅号**（个人只能选这个）
3. 填邮箱 → 收激活邮件 → 设密码
4. 主体类型选 **个人**，填姓名、身份证号、手机号
5. 用本人实名微信扫码，完成人脸核验
6. 填昵称、头像、简介、内容类目，提交

审核一般当天通过。昵称个人号一年可改 2 次，内容类目会影响推荐流量，慎选。

## 二、拿 AppID 和 AppSecret

> 2025 年 12 月 1 日起，「设置与开发 - 开发接口管理」已整体迁到**微信开发者平台**。后台里点这一项会自动跳转过去，直接在开发者平台操作即可。

1. 打开 https://developers.weixin.qq.com ，或在后台点「设置与开发 → 开发接口管理」跳转
2. 左侧「我的业务与服务」里选中你的公众号
3. 「基础信息」页复制 **AppID**（开发者 ID）
4. 切到「开发密钥」页，点 AppSecret 的启用/重置，管理员微信扫码
5. **AppSecret 只完整显示一次**，立刻复制，填进 `.env`

## 三、配 IP 白名单

在开发者平台同一个公众号下找「API IP 白名单」（旧后台叫「IP 白名单」）：

1. 先随便跑一次 `python check.py`
2. 如果报 `40164`，报错里会直接给出你的出口 IP，形如 `invalid ip 1.2.3.4`
3. 把这个 IP 填进白名单，保存
4. 再跑一次 `python check.py`，看到 `[OK] access_token` 就成了

注意事项：

- 填的是**公网出口 IP**，不是 `192.168.x.x` 这种内网地址
- 家用宽带 IP 会变，变了就重新加一条（白名单不支持网段，只能一条条填）
- 换电脑、换网络环境都要重新加

## 四、验证

```
python check.py
```

三项全 OK 就通了：

```
[OK] access_token：...
[OK] 草稿箱接口：当前 0 篇草稿
结论：链路已通，可以开始推稿了。
```

## 五、群发

推完稿子后：

- 方式一：手机装「公众号助手」App → 草稿箱 → 打开 → 群发
- 方式二：电脑后台「内容管理 → 草稿箱」→ 预览 → 群发

订阅号每天 1 次群发额度，一次最多 8 篇。**群发才会推送给粉丝**，接口「发布」只是公开到主页，两者别混。

## 六、合规

AI 辅助生成的图文，发布时需要按要求声明。脚本默认会在文末追加一行声明，如果不需要可以加 `--no-disclosure` 关掉，但建议保留。
