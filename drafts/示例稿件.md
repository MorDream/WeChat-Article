## 为什么要做这件事

每天写公众号最累的不是写，是**排版和搬运**。把同一份 Markdown 复制进编辑器，重新调字号、调间距、传封面，二十分钟就没了。

这套流程把中间那段全部交给脚本，我只保留两个动作：定选题、点群发。

> 自动化的边界要提前说清楚：个人订阅号没有发布接口权限，最后一步群发必须人工确认。

## 它做了什么

1. 读取 Markdown 稿件，自动识别标题和摘要
2. 把正文里的本地图片传到微信图床，替换链接
3. 上传封面，拿到 media_id
4. 调草稿接口写入，稿件出现在后台草稿箱

| 环节 | 谁来做 | 耗时 |
| --- | --- | --- |
| 选题 | 定时任务 + 人工确认 | 2 分钟 |
| 写稿排版 | 脚本 | 自动 |
| 群发 | 手机点一下 | 30 秒 |

## 一段代码长什么样

```python
client = MPClient(appid, secret)
thumb_id, how = client.upload_cover("cover.png")
media_id = client.add_draft(article)
```

到这里，稿子就已经躺在草稿箱里了。
